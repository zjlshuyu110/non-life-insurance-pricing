python -m pip install -r requirements-neural.txt

python scripts/prepare_text_demo.py --download-model
python -m nonlife.text_pricing
python scripts/build_text_showcase.py
Fit base GLMs first with python -m nonlife.run. For new English text, use --input data/text_demo/example_input.json --output result.json. Inference is local; the model download is about 133 MB.
